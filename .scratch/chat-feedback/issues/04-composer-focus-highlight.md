## Agent Brief

**Category:** bug

**Summary:** Use one visible input focus indicator on the Chat composer row while preserving the Send button's separate keyboard indicator.

**Current behavior:**

The composer row highlights its border when a child has focus. The input also receives a focus-visible outline.
This produces two nested highlights around the input on desktop and narrow layouts.
The Send button shares the input's outline rule and needs to retain its own visible keyboard focus indicator.

**Desired behavior:**

Use the containing row as the input's visible focus indicator. Remove the duplicate input outline without exposing a replacement browser-default outline.
Keep a distinct visible keyboard focus indicator on Send so keyboard users can distinguish the button from the input.
Keep existing input focus, Tab navigation, sending, draft, and disabled-state behavior.

**Key interfaces:**

- `ChatPanel`: the composer form, input, containing row, and Send button.
- `.chatInputRow:focus-within`: the existing containing-row focus treatment.
- `.chatComposer input:focus-visible` and `.chatComposer button:focus-visible`: separate the input and button styling without removing the button's focus indicator.

**Acceptance criteria:**

- [x] A focused, enabled input has one visible focus treatment on its containing row, with no duplicate input outline.
- [x] The input remains visibly focused during keyboard navigation and pointer interaction.
- [x] With a nonempty draft, Tab moves from the input to Send, which retains a distinct visible keyboard focus indicator.
- [x] Moving focus outside the composer clears its focus treatment.
- [x] An empty draft leaves Send disabled. Existing input and button disabled states remain correct when Chat sending is unavailable or restricted.
- [x] Desktop and mobile-width checks cover enabled and disabled composer states. Inspect the appearance before and after the change.
- [x] Draft handling, submission, and existing focus recovery behavior remain unchanged.

**Out of scope:**

- Composer layout, sizing, colors, or Send button redesign.
- Global focus-style changes or new UI dependencies.
- Changes to sending, moderation, playback, or Chat access rules.
