# 07: Add a Chat text size setting

Status: ready-for-agent
Category: enhancement
Priority: Normal
Blocked by: none

## Request

Add a font size or scale setting for Chat.

## Evidence

Chat settings currently contain only the timestamp toggle. The timestamp preference persists in browser storage.

## Accepted behavior

The user selected message text size, saved in this browser. The setting does not scale the entire Chat panel.
Use small, default, and large choices. Choose the exact sizes during implementation and verify readability.

## Proposed acceptance criteria

- The setting is available from Chat settings.
- Changes apply immediately and persist after reload.
- The default preserves the existing size.
- Long messages wrap without horizontal overflow.
- Timestamp, author, and message layout remain readable at each size.
- The virtualized transcript recalculates row heights without losing the reading position.
- The setting works with keyboard navigation and mobile touch.
