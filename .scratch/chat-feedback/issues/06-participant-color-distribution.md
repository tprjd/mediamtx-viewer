# 06: Investigate repeated Chat participant colors

Status: needs-triage
Category: bug
Priority: Low
Blocked by: none

## Request

Chat participant colors do not appear random. The reporter has only a small sample.

## Evidence

The message component assigns one of six colors by summing the character codes in the Chat author tag and taking the remainder.
The assignment is stable. Different participants can share a color.
The accepted Chat design requires consistent participant colors. The author-identifier ADR requires a stable tag, not a unique color.

## Investigation

Measure the color distribution for a representative set of generated Chat author tags.
Check whether the report concerns repeated colors, biased distribution, or a preference for a larger palette.

## Acceptance criteria for investigation

- Record sample size and counts for each color.
- Distinguish expected collisions from a distribution defect.
- Preserve stable colors across messages and reloads.
- If a change is warranted, propose a readable palette and assignment rule before implementation.

## Comments

Recommended outcome: needs-triage until the distribution is measured.
A new random color for every message would conflict with the accepted design.
