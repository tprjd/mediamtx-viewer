## Agent Brief

Category: enhancement

Summary: Expand Chat participant name colors from six to 12.

### Accepted direction

On 2026-09-17, the maintainer accepted 12 colors with stable assignment across
messages and reloads. Shared colors remain possible. This brief supersedes the
earlier investigation-only scope.

### Verification

The current `ChatMessage` assignment expression was evaluated against all 65,536
four-character lowercase hexadecimal tags. Counts in palette order were:

- Six colors: 10926, 10924, 10921, 10920, 10921, 10924.
- Twelve colors: 5438, 5520, 5586, 5624, 5619, 5568, 5488, 5404, 5335, 5296, 5302, 5356.

To reproduce, enumerate integers 0 through 65535, convert each to hexadecimal,
pad to four characters, and count the character-code sum modulo the palette size.
This enumerates possible tags rather than sampling production participants.
The six-color distribution is nearly uniform. Twelve colors receive 8.08%–8.58%
each. These results support retaining the existing assignment rule.
Tags extended after a collision were not included in this distribution check.
Repeated colors in a small room do not establish a distribution defect.

### Current and desired behavior

`ChatMessage` uses the sum of the Chat author tag's character codes modulo six.
Expand the palette to 12 and retain that rule with the new palette length.
The full tag, including any collision extension, determines the color.
Existing participants may receive a different color when this change ships.
For an unchanged tag and palette, the color remains stable after that change.

Keep the existing six colors. Suggested additions are `#fca5a5`, `#c4b5fd`,
`#93c5fd`, `#5eead4`, `#bef264`, and `#f0abfc`. The implementing agent may adjust
these additions after checking contrast and visual distinction in Chat.
Record the final palette and verify it before completing implementation.

### Key interfaces

- `ChatMessage`: participant name palette and deterministic assignment.
- `PublicChatMessage.authorTag`: use the full value without changing its meaning.
- `allocateChatAuthorTag`: preserve existing tag generation and collision handling.

### Acceptance criteria

- [ ] The participant name palette contains exactly 12 distinct colors.
- [ ] Every color has a contrast ratio of at least 4.5:1 against the Chat background.
- [ ] The same tag produces the same color across messages and reloads.
- [ ] Assignment supports both four-character and extended tags.
- [ ] A focused runnable check verifies stability and that all 12 colors are reachable.
- [ ] Record distribution counts for the final rule using the exhaustive check above.
- [ ] Inspect the palette in desktop and mobile Chat for readability and visual distinction.
- [ ] Chat author tags, role badges, message text, and removed messages keep their existing behavior.

### Out of scope

Unique colors per participant, random colors per message, user-selected colors,
new settings, account data changes, and changes to Chat author tag generation.
