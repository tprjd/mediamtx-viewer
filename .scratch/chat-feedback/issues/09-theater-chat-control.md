# 09: Integrate the theater Chat button with player controls

Status: needs-triage
Category: bug
Priority: Normal
Blocked by: none

## Request

In theater mode, the Open chat control overlaps the playback mode control. It stays visible when player controls hide.
Use only the Chat icon as its visible content.

## Evidence

`TheaterChatRestore` renders an absolutely positioned button at the top right, outside `Controls.Root`.
It includes visible Open chat text. Its CSS has no player-control visibility condition.
The overlap still needs browser verification at the affected viewport.

## Proposed acceptance criteria

- The closed-Chat button shows only its icon and retains an accessible Open Chat name.
- The button does not overlap the playback mode control at supported desktop and mobile widths.
- Visibility follows the player controls, including pointer, touch, and keyboard use.
- Keyboard focus makes the control available.
- Opening Chat restores the existing focus behavior.
- Closing Chat and leaving theater mode preserve the saved Chat preference.

## Scope

Change presentation and control visibility. Playback mode selection and transport behavior remain unchanged.
